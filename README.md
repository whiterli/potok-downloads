<h1 align="center">Поток для Windows</h1>

<p align="center">Программа для проверки счетов поставщиков</p>

## Скачать

[**Скачать «Поток» 1.5.2 для Windows x64**](https://github.com/whiterli/potok-downloads/releases/download/v1.5.2/Potok-1.5.2.exe)

Для скачивания аккаунт GitHub не нужен. Откройте `Potok-1.5.2.exe` из папки «Загрузки». Программа запускается без установки.

## Попробовать

1. Откройте [страницу кейса №04](https://navicons.com/careers/ai-fest-2026/cases/#case-04) и нажмите **XLSX ↓** в блоке «Что вам дают».
2. В «Потоке» нажмите **«Выбрать файл XLSX»** и откройте скачанную таблицу.
3. Найдите письмо **В-15**. Программа покажет, почему сумма счёта №52 завышена на 1 000 ₽.
4. Нажмите **«Скачать результаты в Excel»**, чтобы сохранить отчёт.

Если программа просит WebView2, скачайте **Evergreen Bootstrapper** со [страницы Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

У EXE нет цифровой подписи, поэтому Windows может показать предупреждение SmartScreen. [Что означает предупреждение](https://learn.microsoft.com/windows/apps/package-and-deploy/smartscreen-reputation)
